# xzyu02.github.io

Personal website built with React + Vite.

## Main Structure

- `src/` app code (components, styles, content)
- `public/` static files
- `.github/workflows/deploy-pages.yml` GitHub Pages deployment workflow

## Local Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy

- Deployment is automatic via GitHub Actions on push to `main`.
- GitHub Pages source must be set to `GitHub Actions`.
